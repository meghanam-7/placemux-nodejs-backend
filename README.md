# PlaceMux Node.js Backend - Phase 1

## Overview

This project was created as part of the **PlaceMux (Altrodav Technologies) Phase 1 Industry Immersion Program**.

The objective of this project is to build a clean and scalable Node.js backend from scratch using Express.js while following industry best practices.

---

## Tech Stack

- Node.js
- Express.js
- dotenv
- Nodemon
